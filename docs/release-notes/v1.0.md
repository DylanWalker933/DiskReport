## 功能

- 扫描整个磁盘（默认 D 盘），按**每个文件夹的占用容量**从大到小排序
- 列出**每个文件夹中体积最大的文件**，直接定位"空间去哪了"
- 输出自包含 HTML 报告：可排序、可搜索、可按体积筛选、可展开每个文件夹的大文件明细；另附 CSV / TXT
- 多线程并行扫描，固态硬盘上全盘扫描通常只需数秒，支持随时中断
- **只读扫描**：仅调用 `os.scandir` / `entry.stat` 读取目录与元数据，不改动任何被扫描的文件
- 跳过符号链接与目录联接（junction），不重复计数、不会死循环；支持超过 260 字符的超长路径
- 权限不足的目录单独记录在"无法访问"清单中，不中断整体扫描

## 用法

双击运行，默认扫描 `D:\`；也支持命令行模式（便于配合任务计划程序定时生成报告）：

```bat
DiskReport.exe --cli --root D:\ --out D:\报告\D盘空间报告 --format all --workers 12
```
